# 场外衍生品工作助手 1.0

适用：Windows 10 / 11，Intel / AMD 64 位电脑。

## 打开软件

1. 将 `场外衍生品工作助手_Windows_x64_v1.0.0.zip` 完整解压到本地文件夹。
2. 双击其中的 `场外衍生品工作助手.exe`。
3. 保留旁边的 `_internal` 文件夹，这是软件运行所需的组件；不要单独复制 EXE。

无需安装 Python、VS Code 或配置环境。OCR 模型和空白模板已包含在软件包内，材料在本机识别。查看生成的 Excel 时使用电脑已有的 Excel 或 WPS。

## 客户信息登记

左侧选择“客户信息登记”。把单家客户文件夹拖入材料框，或选择包含多家客户的上级目录。文件夹内保持原有的 `0.OA`、`1.开户材料存档` 结构和材料编号。

确认待处理客户列表，选择结果保存目录，点击“开始登记”。完成后点击“打开结果表”或“打开结果目录”。

结果包括两张工作表的登记表、逐项来源核对 JSON 和待核对 TXT。无法确认的字段留空标黄，依据原材料补填。经营范围取 KYC 基本信息表 C14；授权人从交易授权表 B14 起汇总非空姓名。财报自动判断方向、按关键词取值；评分使用局部复核。

## 问卷分数等级

左侧选择“问卷分数等级”，选择处理方式：

- **提取答案并评分**：拖入 `.docx` / PDF 问卷，或选择直接存放问卷的文件夹，生成含 A:W 的分数统计表。
- **仅提取答案**：提取客户名称和 20 题答案到 A:U，总分和等级留空。
- **仅计算等级**：选择已有的 `.xlsx` 分数统计表，按 A:U 的答案计算 V:W，并输出新副本。

PDF 支持文字版和扫描版。答案仍需写在题目段落末尾，不能只在选项上打勾；第 13、17 题支持多选。旧 `.doc` 请用 Word / WPS 另存为 `.docx` 后再使用。任何问卷缺题或格式错误时会停止交付本批统计表，并显示原因。

## 输出与停止

每次运行在所选输出目录下创建独立的结果文件夹。程序使用内置空白模板，保持原有表头、金额单位和评分规则。输入文件、已有统计表不会被覆盖。

处理中窗口可正常操作；“停止处理”终止当前任务，不交付未完成的结果。处理失败时看窗口下方的原因，修正材料后重试。

首次识别或材料较多时请耐心等待。已处理材料会缓存识别结果，加快重复运行。用户设置、任务日志和 OCR 缓存位于当前用户 `%LOCALAPPDATA%\AccountWorkbench`，不写入软件安装目录。

## 迁移与更新

给同事发送完整 ZIP 软件包即可，不需要发送客户资料或开发代码。更新时解压新版软件到新目录，再打开新 EXE；业务材料及输出结果保存在你选择的位置。

若误删 `_internal` 或出现模型缺失，请重新完整解压。保存目录不可写时更换目录；打开结果表失败时，可点击“打开结果目录”后用 Excel / WPS 打开。
