# 客户信息登记

在 `exe` 根目录运行：

```powershell
.\.venv\Scripts\python.exe "account\客户信息登记\登记.py"
```

默认遍历本目录下含 `0.OA` 或 `1.开户材料存档` 的客户文件夹，将所有客户写入同一个登记表的两张工作表，从第 3 行开始。模板保持原样，结果保存在 `结果`，文件名带时间戳，已有文件不会覆盖。依赖使用根目录 `requirements.txt`。

参数：

- `--root "路径"`：指定客户资料根目录。
- `--customer "396、某公司-C4"`：只处理指定客户文件夹。
- `--output "新文件.xlsx"`：指定结果文件。
- `--template "模板.xlsx"`：指定模板。

每个结果附带 `.核对.json`（逐字段取值、来源、OCR 原文和状态）和 `.待核对.txt`。表格单元格批注同样记录来源；无法确定的字段留空并标黄。OCR 缓存位于 `.ocr-cache`，根据原文件内容、页码、旋转、裁剪、方向分类与印章过滤参数区分，原文件或识别版本变更后自动重新识别。资料使用本地 RapidOCR，不上传。

实施规则：

- KYC 对应关系定义在 `登记.py` 的 `KYC_MAP` / `AUTH_MAP`。L 公司资质读取基本信息表 C8。N 列固定读取 `0.OA/00.KYC（尽职调查表）.xlsx` 的 sheet1（实际名称“基本信息表”）C14，不再从营业执照提取；旧参数 `--scope-source` 已移除。O 列使用基本信息表 C21；Q 只取有效期截止日期。
- 交易人员页 C、E、F、G、H 分别读取 KYC 交易授权表 B、H、E、F、I 列，从第 14 行到表尾。按非空姓名所在行逐人配对，以中文逗号连接，保留重复的手机号、邮箱等信息；G 保留完整有效期。核对五项数量以及行号，缺项或错误使对应列留空标黄；有授权信息但姓名为空或错误时整组待核对。客户名称与目录编号用于关联两张表。
- R 列遍历第 13 号受益人采集表全部页面中的“股东/控制人/高管”姓名，按出现顺序去重，用“、”连接；S 身份证号码、T 完整起止有效期在对应人员区块内识别，以 R 的姓名顺序连接。兼容扫描表“有限期”文字和单元格换行；检查号码位数、出生日期和 18 位号码校验位。同名人员证件信息冲突或 OCR 低置信度时留空标黄；空白预留栏不作为人员。
- 注册资本将中文大写金额换算为万元。财报逐页按文字方向及关键词判断是否旋转，遍历全部页面，按资产合计/资产总计、负债合计/负债总计、净利润等行标题及期末余额、本年累计金额等列标题取值，检查单位后换算为元，不限定页码和金额的固定位置。跨页表格仅在行次连续且列对齐时沿用前页表头和单位。若红色印章遮挡部分表头，过滤印章后补读表头，金额仍取原始彩色识别。净资产 AF 按 AD 总资产减 AE 总负债计算；关键词、单位不明、置信度不足或多处金额不能唯一确定时留空标黄。
- AM 只接受第 18 题题干末尾的答案字母，再读取对应选项的损失比例；勾选答案留空待核对。
- 资信日期校对第一页右上和第二页左下；评分校对第二页各处“综合评分”填写栏，排除分类说明文字。每处数字局部放大两次，并锁定原文字方向，避免手写 81 被方向分类器翻转后识别成 18；局部复核失败或多处不一致时留空标黄。AR：≥80 为正常，60<分数<80 为关注；≤60 未定义，留空待核对。
- BA 读取 C4、C5、C4低买高、B类专业交易者后缀，无这些后缀时为专业交易者；AK 与 BA 一致。
- 保留模板首条记录的固定默认值；未要求的字段不从材料额外推断。AD–AG 保留数值，显示格式为 `#,##0.00`；BC 为 `0.0`。AH 继续使用总负债/总资产公式，显示格式为 `0.00%`，公式不再乘 100，空值或除零时显示空白。
