# Pan 持仓报告

从 `exe` 根目录运行：

```powershell
.\.venv\Scripts\python.exe trader\main.py
```

依次输入 `Pan` → `ccbg` → `A` 或 `B`。选择 `jsd` 则进入原来的结算单/确认书流程。

## A：盖章前

将表格放在 `trader/Pan/持仓报告` 的第一层，支持 `.xlsx`、`.xlsm` 和 `.xls`。程序忽略 `~$` 临时文件、已生成的 PDF 和子目录。

```powershell
.\.venv\Scripts\python.exe trader\main.py --Pan --mode ccbg --A
```

- 登记表直接使用表格的完整文件名主体（只去扩展名），顺序与 PDF 合并顺序相同。
- 只处理“账户状况、持仓明细、历史交易、资金明细”，按此顺序拼接；不调用 `precheck.py`。
- 空的持仓明细/历史交易不产生页面；账户状况和资金明细作为首尾校验依据，若为空会提示核对。
- 保留单元格格式和数据，只调整临时打印副本。历史交易按横向 A4 排版，PDF 内容再左转 90°，使最终每一页都是竖版 A4。
- 其他 sheet 按竖版 A4 打印，宽度不足时缩小，长表按高度分页。资金明细每页重复前两行表头，便于阅读和扫描识别。
- 合并时不插入凑偶数的空白页。请使用 A4 竖版、单面打印；A 本身只生成可打印文件，不直接调用打印机。

产物路径：

| 文件 | 位置 |
| --- | --- |
| 每家公司原名 PDF | `Pan/持仓报告/持仓PDF单独_YYYYMMDD_批次/` |
| 持仓批次记录 | 同目录下的 `持仓批次记录.json`，B 需要保留 |
| 登记表 | `Pan/登记表文件/登记表_持仓报告_Pan_YYYYMMDD_批次.xls`，同时复制到桌面 |
| 合并 PDF | `Pan/合并PDF/持仓报告合并_Pan_YYYYMMDD_批次.pdf`，同时复制到桌面 |

日期是本次用印日期。持仓和 `jsd` 分别计算批次；再次运行 A 默认生成下一批。指定已完成批次时，只有原表格和现有产物一致才复用，不覆盖已经盖章的批次。

## B：盖章后

将整批扫描 PDF 放到 `Pan/持仓报告扫描`，按扫描当天的月日命名，例如 `0909.pdf`：

```powershell
.\.venv\Scripts\python.exe trader\main.py --Pan --mode ccbg --B
```

B 默认查找最近一次完成的 **ccbg A 批次**，不会选到结算单批次。另一天或另一批可手动指定：

```powershell
.\.venv\Scripts\python.exe trader\main.py --Pan --mode ccbg --B --task-date 20260909 --batch 1
```

也可以用 `--scan-source "完整扫描件路径.pdf"` 指定扫描源；相对路径相对于 `Pan/持仓报告扫描`。先检查拆分计划可加 `--dry-run`。

B 使用本地 OCR 识别打印页面上的“持仓报告、客户编号、客户名称”或“账户状况”，再核对资金明细、客户信息和 A 记录页数。整份公司的先后次序可以调整，但每家公司内部页面须保持顺序。识别不清、漏页、重页或夹入空白背面时停止，避免错名。拆分 PDF 完整保留扫描页面及印章。

持仓路径只 OCR 页顶区域，避免逐格识别密集交易表；确认书原有的页顶/页尾 OCR 范围保持不变。

拆分件写入 `Pan/持仓报告扫描/持仓扫描件_扫描日期_Pan_A日期_批次/`，文件名与表格主体完全相同；桌面生成同名 ZIP。不要删除 A 的批次记录，原表格日后移走不影响 B。

## 转换依赖与检查

Python 依赖沿用根目录 `requirements.txt`。表格转 PDF 使用本地 LibreOffice，程序依次查找 `TRADER_SOFFICE` 环境变量、PATH、`exe/.tools/LibreOffice/program/soffice.com` 和常规安装位置。原表格不上传网络，也不保存打印设置变更。

打印副本由 LibreOffice 的 [本地 PDF 导出接口](https://help.libreoffice.org/latest/en-US/text/shared/guide/pdf_params.html) 生成。换电脑时保留项目内 `.tools/LibreOffice`，或安装 LibreOffice 并通过 `TRADER_SOFFICE` 指定路径。

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s trader\tests -v
.\.venv\Scripts\python.exe trader\main.py --Pan --mode ccbg --A --dry-run
```
